# Sorting Visualizer

A visual demonstration of various sorting algorithms built with [Raylib](https://www.raylib.com/).

## Sorting Algorithms

- **Bubble Sort** - Simple comparison-based sorting
- **Quick Sort** - Efficient divide-and-conquer sorting
- **Bogo Sort** - Randomized sorting (for fun!)

## Requirements

- C compiler (GCC/Clang)
- Raylib library
- Make

## Build

```bash
make
```

## Run

```bash
./sortingVisualizer
```

## Project Structure

- `src/` - Source files (.c)
- `include/` - Header files (.h)
- `Makefile` - Build configuration
